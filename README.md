# Portfolio Website

A fully responsive, professional personal portfolio website built with HTML, CSS, and modern JavaScript.

## Features

### Design
- **Color Palette**: Deep black background with elegant purple accents and gradients
- **Minimal, Premium Aesthetic**: Inspired by high-end tech portfolios
- **Smooth Animations**: Micro-interactions, hover effects, section reveals, and button transitions
- **Modern Typography**: Clean sans-serif (Inter), strong hierarchy, and good letter spacing
- **Dark Mode Optimized**: Excellent contrast and accessibility

### Sections
- **Sticky Navigation Bar**: With smooth scrolling and mobile hamburger menu
- **Hero Section**: Bold headline, professional tagline, and call-to-action buttons
- **About Section**: Profile image placeholder and professional bio with stats cards
- **Skills Section**: Animated progress bars showing technical abilities
- **Projects Section**: Interactive cards with hover effects, filtering, and project links
- **Services Section**: Clean icons and structured content for offerings
- **Contact Section**: Modern form with floating labels and social media links
- **Footer**: Copyright and minimal branding

### Technical Implementation
- **Semantic HTML5**: Clean, accessible structure
- **CSS Variables**: For colors, spacing, and typography
- **Pure JavaScript**: No frameworks - handles animations, interactions, and form handling
- **Mobile-First Design**: Fully responsive on all screen sizes
- **Performance Optimized**: Intersection Observer for scroll animations, throttled scroll events
- **SEO Ready**: Meta tags, semantic markup, and proper heading hierarchy

### Unique Touches
- Glowing purple accents on hover
- Animated gradient borders and highlights
- Smooth scroll-based animations
- Interactive hero blob with parallax effect
- Project filtering system
- Animated skill progress bars

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Customize the content with your own information

## Customization

### Colors
Edit the CSS variables in `css/styles.css`:
```css
:root {
    --color-primary: #9333ea;         /* Main purple */
    --color-primary-light: #a855f7;   /* Light purple */
    --color-primary-dark: #7c3aed;    /* Dark purple */
    /* ... other variables */
}
```

### Content
- Update personal information in `index.html`
- Replace placeholder images with your own photos
- Modify skills, projects, and services sections
- Update contact information and social links
